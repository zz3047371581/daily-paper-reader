## 摘要
长音视频推理对于全模态大语言模型而言十分困难，因为决定性证据往往稀疏、跨模态，且使用统一高保真输入进行保存成本过高。我们推出了OmniReasoner，一个面向长音视频思考的工具使用后训练框架：全模态大语言模型通过监督微调和强化学习，学会在回答前判断是否需要调用缩放工具以及调用位置。OmniReasoner首先构建整个流的低成本全局预览，然后在需要时，调用缩放工具并指定所需的时间区间，以在回答前进行更高保真度的视觉和听觉检查。由于模型在调用前后观察到不同的采样粒度——稀疏的全局预览和更密集的局部片段——我们引入了TimeAnchor，它使工具的时间参数在这些粒度间保持有效且往返一致，而非绑定到特定采样率下的帧索引。为使这种工具使用行为可训练，而无需昂贵的手动区间标注，我们构建了一个时间增强数据引擎，通过视频编辑与合成来生成工具使用后训练轨迹。在多个全模态和视频基准上的实验表明，OmniReasoner提高了答案准确率和时间定位能力，同时将高保真计算集中在信息丰富的区域。代码开源在https://github.com/RockyChen0205/OmniReasoner。

## Abstract
Long audio-video reasoning is difficult for omnimodal LLMs because the decisive evidence is often sparse, cross-modal, and too expensive to preserve with uniformly high-fidelity inputs. We introduce OmniReasoner, a tool-use post-training framework for Thinking with Long Audio-Video: omni-modal LLMs learn, via supervised fine-tuning and reinforcement learning, to decide whether and where to call a zoom-in tool before answering. OmniReasoner first builds a low-cost global preview of the full stream and then, when needed, calls the zoom-in tool with a requested temporal interval for higher-fidelity visual and audio inspection before answering. Because the model observes different sampling granularities before and after this call -- a sparse global preview and a denser local clip -- we introduce TimeAnchor, which keeps the tool's temporal argument valid and round-trip-consistent across these granularities, rather than tied to frame indices from a particular sampling rate. To make this tool-use behavior trainable without expensive manual interval annotation, we build a Temporal Augmented Data Engine that synthesizes tool-use post-training trajectories by video editing and composition. Experiments across omnimodal and video benchmarks show that OmniReasoner improves both answer accuracy and temporal grounding while concentrating high-fidelity computation on informative regions. Code is available at https://github.com/RockyChen0205/OmniReasoner.

### **1. 论文核心问题与整体含义 (研究动机和背景)**

*   **核心问题**: 长音视频推理对全模态大语言模型构成巨大挑战。关键证据（一个短暂的动作、一句对白、一个背景音等）通常是 **稀疏的、跨模态的**，并且均匀地对整个长视频进行高保真处理会消耗巨大的计算资源，导致上下文窗口不堪重负。
*   **研究动机**: 现有方法或是局限于单模态视觉搜索，或是虽进行联合感知但在固定预算下处理证据，而缺乏一种机制让模型自主决定 **是否、何时、何地** 需要投入高保真计算资源。这类似于人类的“快速浏览-拖拽进度条回看”策略。
*   **整体含义**: 本文旨在通过 **原生工具使用** 的后训练方法，教会全模态模型一种 **计算策略**：在长音视频流中，先进行低成本全局扫描，然后像使用一个“缩放镜”工具一样，只在怀疑有证据的时刻进行高保真、跨模态的聚焦检查，从而高效地分配有限的算力并提升推理准确性。

### **2. 论文提出的方法论 (核心思想、关键技术细节、公式或算法流程)**

*   **核心思想: 基于工具使用的自适应证据采集**
    *   将长音视频推理建模为一个 **工具使用决策问题**。模型不再是单次、均匀地处理输入，而是分两步走：
        1.  **全局观察**: 以低帧率、低保真度快速扫描整个音视频流，形成对全局时间线（`g`）的概括性理解。
        2.  **局部聚焦**: 基于全局观察，模型自主决策：是直接回答（`answer(y)`），还是调用一个“缩放”工具（`zoom([s, e])`），以获取指定时间区间的更高保真局部片段（`z`）。最终答案（`y`）则结合全局上下文和局部证据得出。

*   **关键技术1: TimeAnchor —— 跨粒度时间锚定**
    *   **解决的问题**: 模型在全局预览（稀疏采样）和局部缩放（密集采样）之间切换时，相同物理时刻（例如第32秒）在不同采样网格下对应的帧索引不同，导致工具调用的时间参数失效。
    *   **技术细节**: TimeAnchor 在每个两秒的视频块（chunk）前添加一个 **绝对时间文本标记**（如 `<0 seconds>`, `<2 seconds>`）。这使得模型在请求缩放区间时，使用的是与采样粒度解耦的 **绝对秒数**（如 `zoom([32, 38])`），无论在任何查看阶段，该参数都指向原始流中的同一时刻，确保了往返一致性。

*   **关键技术2: 时间增强数据引擎与时序合成**
    *   **解决的问题**: 工具使用行为（何时调用、指向何处）的监督数据极其稀缺，手动标注成本高昂。
    *   **技术细节**: 通过两种无需人工标注的 **视频编辑与合成技术** 自动构建训练任务，并生成包含“思考-调用工具-返回证据-回答”的完整轨迹。
        1.  **多片段合成**: 将多个短片段拼接成长视频，将每个问题关联至一个源片段。源片段时间偏移即构成了“证据区间”的真值标签。
        2.  **异常插入**: 在长视频的某一时段，将音频、视频或两者替换为其他源片段。模型需识别异常类型和区间，替换窗口直接提供了区间真值标签。
        *   然后，通过 `MediaSandbox`（一个基于 FFmpeg 的沙箱环境）模拟推理时的全局-局部接口，让一个教师模型（如 Gemini）根据构造好的区间合成多样化的工具使用训练轨迹，并经过严格的过滤与质量检查。

*   **算法流程**:
    1.  **监督微调阶段**: 使用合成的工具使用轨迹、直接回答轨迹以及辅助的全模态数据，对基础模型进行冷启动训练，使其掌握工具调用的格式与基本策略。
    2.  **强化学习阶段**: 采用 **群组相对策略优化** 算法。奖励函数由答案正确性（`Racc`）和格式合规性（`Rfmt`）组成，不单独奖励调用工具行为。调用工具的唯一价值在于提高最终答案的正确性。模型通过探索，学习在更优的时机、指向更准的位置调用工具。

*   **实验场景**: 主要关注 **长视频推理** 场景，尤其是在不同视频时长（0-30分钟甚至更长）和不同音频类型（音乐、环境音、语音）下的表现。

    *   **充分**: 实验设计较为全面。它不仅在最终答案准确率层面验证，还对模型的学习行为（何时调用工具）、内部机制（注意力如何分配）以及框架关键组件的有效性（TimeAnchor、数据配方、训练范式）进行了详尽分析。

### **6. 论文的主要结论与发现**

*   **有效性**: OmniReasoner 在所有全模态和视频基准上均超越基座模型 Qwen2.5-Omni-7B，尤其是在需要稀疏证据定位的复杂长视频任务上提升显著（如LVOmniBench提升3.4%，VideoHolmes提升15.6%）。
*   **可扩展性**: 自适应缩放的优势与视频长度呈正相关。视频越长，模型调用缩放工具的比例越高，通过工具使用获得的性能增益也越大。
*   **组件必要性**: 消融实验证明，自研的时间增强数据、工具使用轨迹、完整的SFT+RL训练范式、输入中的音频模态以及返回的缩放片段，对最终性能都至关重要。TimeAnchor在确保时间定位的准确性上起到了关键作用。
*   **行为合理化**: 模型学会了合理的行为模式：对简单问题倾向于直接回答，对需要额外证据的复杂问题则主动调用工具。

### **7. 优点 (方法或实验设计的亮点)**

*   **创新性地将计算资源分配建模为学习问题**: 让模型“学会何时偷懒，何时努力”是一个非常贴合实际应用场景的核心思想。
*   **TimeAnchor 设计简洁而有效**: 通过简单的文本标记解决了跨模态、跨采样粒度的时序对齐难题，无需复杂架构改动，思想可迁移。
*   **巧妙的数据合成方案**: “时间增强数据引擎”无需昂贵的人工标注，通过视频编辑与合成自动生成了问答、证据区间和工具使用轨迹的多重监督信号，极大提升了方法的可扩展性。
*   **实验设计全面且深入**: 不仅有性能对比，还包含行为分析、注意力可视化、多维度消融等，立体地证明了方法有效性，增强了结论的可信度。

### **8. 不足与局限 (实验覆盖、偏差风险、应用限制等)**

*   **模型能力与基础设施限制**: 实验仅基于 7B 参数的较小模型，且上下文窗口仅 32K。论文坦诚指出，受限于资源和基础设施成熟度，未能在更大的、具有原生工具使用预训练的模型上进行多轮交互式探索。
*   **工具范围过于单一**: 目前仅实现了“缩放”这一个感知类工具。对于需要结合外部知识、执行代码或进行结构化查询的复杂任务，框架尚不能处理。
*   **训练数据潜在偏差**: 尽管数据合成方式巧妙，但用于合成轨迹的教师模型本身可能存在偏见或不完美，这种偏差可能传递给学生模型。合成的异常检测任务可能无法完全覆盖真实世界的各种复杂情况。
*   **两阶段推理的局限性**: 当前方法是一个“观察-决策-聚焦”的单次或有限步骤过程，无法像人类一样进行多次、交互式的反复拖拽和检查。
