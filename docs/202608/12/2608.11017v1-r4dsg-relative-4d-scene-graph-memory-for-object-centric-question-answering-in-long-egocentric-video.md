## 摘要
长时程第一人称视频是可穿戴AI助手丰富的底层数据，但诸如物品被移到了哪里、它最后一次状态变化是何时、或它为何被移动等以对象为中心的问题仍然难以回答，因为基于字幕和文字记录的存储器很少保留持久的对象身份或结构化的空间变化。现有长视频问答方法主要强调时间定位和片段检索，而先前的3D场景图方法通常假设比自由运动可穿戴RGB视频所能提供的更强的几何信息，包括点云、RGB-D输入、位姿视图、稀疏重建或重建场景。R4DSG为长时第一人称视频引入了一种相对4D场景图记忆。R4DSG不存储原始图序列，而是将视频转换为紧凑的可查询记忆条目，并按时间、地点、持久对象、相对锚点的变化以及局部交互上下文进行索引。其主要思想是将稳定锚点与动态对象分离，在帧间保持持久的对象身份，并通过相对锚点的转换而非全局对齐的世界模型来表示对象状态。该方法基于近年来纯RGB在可提示视频分割、时序传播和相对3D提升方面的进展，生成可直接用于长时程问答的检索就绪记忆。在EgoLifeQA中一个包含255个对象相关问题的子集上的评估显示，在仅问题检索设置下，相较于EgoRAG-Text总体提升6.7个百分点，在“何时”问题上提升12.5个百分点，这突显了时序化对象记忆的价值。这些结果将相对4D场景图定位为可穿戴助手、AR系统和具身多媒体智能体的实用记忆基础。GitHub页面：https://dualtransparency.github.io/R4DSG/。

## Abstract
Long-horizon egocentric video is a rich substrate for wearable AI assistants, but object-centric questions such as where an item was moved, when it last changed state, or why it was relocated remain difficult because caption- and transcript-based memories rarely preserve persistent object identity or structured spatial change. Existing long-video QA methods mainly emphasize temporal grounding and clip retrieval, while prior 3D scene-graph methods typically assume stronger geometry than free-motion wearable RGB video provides, including point clouds, RGB-D input, posed views, sparse reconstruction, or reconstructed scenes. R4DSG introduces a relative 4D scene graph memory for long egocentric video. Instead of storing raw graph sequences, R4DSG converts video into compact queryable memory entries indexed by time, place, persistent objects, anchor-relative change, and local interaction context. The main idea is to separate stable anchors from dynamic objects, maintain persistent object identity across frames, and represent object state through anchor-relative transitions rather than a globally aligned world model. Built on recent RGB-only advances in promptable video segmentation, temporal propagation, and relative 3D lifting, the method produces a retrieval-ready memory directly usable for long-horizon question answering. Evaluation on a 255-question object-related subset from EgoLifeQA shows, under question-only retrieval, a 6.7-point overall gain over EgoRAG-Text and a 12.5-point gain on when questions, which highlights the value of temporally organized object memory. These results position relative 4D scene graphs as a practical memory substrate for wearable assistants, AR systems, and embodied multimedia agents. ## 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**  
  将视频记忆表示为**稳定锚点 + 动态对象**的结构：
  - **稳定锚点**：桌子、架子、柜台、冰箱、沙发等长期稳定、低运动的参照物；
  - **动态对象**：包、杯子、手机、工具、食品包装等可移动或被操作的物体；
  - 对象状态通过**相对锚点的转换**来描述，而非构建全局一致的世界坐标。

- **任务形式化**  
  给定长时第一人称视频 \(X=\{I_t\}_{t=1}^T\)，构建可查询记忆 \(M=f(X)\)。问答时通过 \(g(M,q)\) 得到答案 \(\hat y\) 与检索证据 \(\hat e\)。输入仅为单目 RGB 视频，不假设深度、点云、标定位姿或全局坐标。

- **相对 4D 场景图表示**
  - 每个采样时间步 \(t\) 构建帧图 \(G_t=(V_t,E_t)\)；
  - 节点包含：空间节点、活动节点、对象节点；
  - 对象节点属性包括：语义类别、掩码/裁剪引用、粗糙 3D 外接框、相对 3D 位置、文本状态描述；
  - 边表示关系，如 `in`、`on`、`near` 以及通用 `spatial_relation`，并可与活动交互线索关联；
  - 将帧级节点关联为持久轨迹后形成 4D 表示（时间索引的 3D 场景图记忆，而非全局一致的 4D 重建）。

- **锚点相对状态与时间事件**
  - 动态对象轨迹 \(p\) 在时间 \(t\) 的状态：
    \[
    z_t(p)=(a_t,d_t,u_t,s_t)
    \]
    其中 \(a_t\) 为主导附近锚点，\(d_t\) 为粗略相对距离，\(u_t\) 为相对方向/布局线索，\(s_t\) 为文本状态。
  - 当动态对象的**主导锚点发生变化且新状态在一段时间内保持稳定**时，写入时间事件：
    \[
    e_i=(p,[t_s,t_e],a^-,a^+,r_i)
    \]
    表示对象、时间跨度、源锚点、目标锚点以及局部原因/交互理由。

- **可查询记忆设计**
  - 将图证据聚合成**段级检索文档**：
    \[
    m_k=(\tau_k,\ell_k,\alpha_k,O_k,Z_k,R_k,I_k,T_k,Y_k)
    \]
    分别对应时间跨度、地点、活动、显著对象集、锚点相对状态、边/关系摘要、交互或词汇变体线索、检索 token、可选解释字段。
  - 记忆写入通过确定性操作：
    \[
    m_k=h(\{G_t\}_{t\in S_k},\{e_i\}_{e_i\cap S_k\neq\emptyset})
    \]
    在段窗口级别聚合帧图和时间事件。
  - 该记忆可序列化为文本或结构化字段，兼容稀疏、稠密或混合检索。

- **端到端流程**
  1. **语义 episode 构建**  
     将长视频划分为活动导向和地点导向片段，每个片段记录时间跨度、地点标签、活动标签与受控对象词汇表：
     \[
     \sigma_k=(\tau_k,\ell_k,\alpha_k,C_k)
     \]
  2. **2D/3D 视觉前端**  
     使用 SAM 3 风格的可提示视频分割，随后用 SAM 3D 风格进行纯 RGB 3D 提升，获得掩码、裁剪、局部轨迹以及相对 3D 元数据（位置、外接框、成对空间关系）。
  3. **帧图构建与持久关联**  
     将 3D 元数据编译为帧图；通过语义兼容性、3D 尺寸连续性、相对位置连续性和附近锚点一致性关联相邻帧中的对象；保守策略防止错误合并；根据低运动和地点一致性推断静态锚点。
  4. **记忆写入**  
     生成时间事件流和段级检索文档，保留地点、活动、对象状态、交互摘要、边摘要、词法变体和时间跨度；在有 why 相关上游注释时写入解释字段。
  5. **问答检索**  
     问题映射到记忆条目检索；主分支检索 top-\(k\)（实验中 \(k=8\)）文档，将结构化字段线性化为证据文本；在**选项盲检索**协议下，回答选项在检索后才引入最终多选题提示；why 问题可选路由到解释感知记忆视图。

## 6. 主要结论与发现

- 在 **question-only retrieval** 协议下：
  - R4DSG Retrieval+ 总体准确率为 **39.6%**，相比 EgoRAG-Text（32.9%）提升 **6.7 个百分点**；
  - 在 **when 问题**子集上，R4DSG 达到 **43.1%**，相比 EgoRAG-Text（30.6%）提升 **12.5 个百分点**；
- 在 **option-blind retrieval / no-why** 协议下，R4DSG 仍保持最强，超过 AMEGO-inspired 基线总体 1.2 个百分点、when 子集 5.6 个百分点；
- No-Transition 控制组低于 R4DSG，说明**持久身份和锚点转换记忆**带来的收益并非仅来自对象/关系序列化；
- WhyMemory 扩展将 why 子集准确率从 33.3% 提升到 40.0%，总体也有小幅提升，但作者强调这是探索性结果；
- 记忆粒度消融显示 **Retrieval+** 在总体和 when 准确率上均最高，说明保留转换事件与地点/活动/对象/交互线索的组合最有帮助；
- 相对 4D 场景图被证明是可穿戴助手、AR 系统和具身多媒体智能体的一种**实用记忆基础**。

## 7. 优点

- **表征设计新颖**  
  将记忆组织为“稳定锚点 + 动态对象 + 锚点相对转换”，避免了对全局一致世界坐标的依赖，适用于自由运动、无深度输入的第一人称视频。

- **面向检索的记忆单元**  
  采用段级 Retrieval+ 文档而不是原始图序列或帧序列，具有良好的压缩率（0.58 MB JSON 覆盖 828 个片段），同时保留了地点、活动、对象状态、交互和边线索。

- **结合现代 RGB-only 基础模型**  
  利用 SAM 3 风格分割和 SAM 3D 风格 3D 提升，在不依赖深度或点云的情况下获取相对 3D 证据，技术上具有可行性和可复现性。

- **实验协议较为严格**  
  使用 question-only retrieval 和 option-blind retrieval 减少选项泄漏；设置 No-Transition 控制组帮助隔离核心贡献；对 why 子集使用无 ground-truth / 无选项的上游生成，降低了数据泄漏风险。

- **对 when 问题的显著提升**  
  12.5 个百分点的提升明确指向时序化对象记忆的价值，这与论文动机高度一致。

- **提供可解释性与证据引用**  
  记忆单元保留时间跨度、锚点转换和局部证据，便于下游 QA 给出带引用的答案。
