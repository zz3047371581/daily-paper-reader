## 摘要
基于技能的 LLM 智能体从外部库中选择可复用流程来解决复杂任务，然而其路由决策完全依赖文本层面信号，如任务描述、语言反思和经验衍生规则，而模型自身的内部表征状态仍未被观测。近期可解释性研究表明，LLM 维持着对行为具有因果影响的线性情感表征；然而，这些表征仅被用于事后分析或直接输出引导，尚未被用于辅助智能体层面的决策。我们提出 Emotion2Skill，一个提取 LLM 内部情感向量并将其同时纳入技能选择与技能演化的框架。在每个决策步骤中，从残差流中提取 27 维情感状态，并将其映射为经过置信度门控的摘要，注入路由提示。除在线选择外，我们还分析情感轨迹中的内部状态突变，以定位存在问题的技能调用，从而指导有针对性的 SOP 重写，取代先前方法中粗糙的二元结果信号。在 WebShop 和 ALFWorld 上，基于 Qwen3-8B 的 Emotion2Skill 相比 Zero-Shot 基线分别将成功率和平均成功率提高了 +26.9% 和 +25.5%，在两个基准上均优于所有基线，并在 Qwen3-14B 上取得一致提升。共激活分析进一步揭示了语义一致的情感—技能配对，确认路由改进反映的是有意义的内部状态信号，而非不透明的统计相关性。这些结果确立了 LLM 内部情感表征作为编排智能体技能系统的有效决策级信号，将其用途扩展到可解释性和输出引导之外。代码可在 https://github.com/BoHan-LIN04/Emotion2Skill 获取。

## Abstract
Skill-based LLM agents select reusable procedures from an external library to solve complex tasks, yet their routing decisions rely entirely on text-level signals such as task descriptions, verbal reflections, and experience-derived rules, while the model's own internal representational state remains unobserved. Recent interpretability work has shown that LLMs maintain linear emotion representations that causally influence behavior; however, these representations have been exploited only for post-hoc analysis or direct output steering, and have not been used to inform agent-level decision-making. We propose Emotion2Skill, a framework that extracts LLM-internal emotion vectors and incorporates them into both skill selection and skill evolution. At each decision step, a 27-dimensional emotion state is extracted from the residual stream and mapped to a confidence-gated summary injected into the routing prompt. Beyond online selection, emotion trajectories are analyzed for abrupt internal-state shifts to pinpoint problematic skill invocations, guiding targeted SOP rewriting that replaces the coarse binary outcome signal of prior methods. On WebShop and ALFWorld, Emotion2Skill with Qwen3-8B improves over the Zero-Shot baseline by +26.9% success rate and +25.5% average success respectively, outperforming all baselines on both benchmarks with consistent gains on Qwen3-14B. Co-activation analysis further reveals semantically coherent emotion--skill pairings, confirming that the routing improvements reflect meaningful internal-state signals rather than opaque statistical correlations. These results establish LLM-internal emotion representations as an effective decision-level signal for orchestrating agent skill systems, extending their utility beyond interpretability and output steering. The code is available at https://github.com/BoHan-LIN04/Emotion2Skill.

- **研究动机**：受神经科学与心理学启发，人类决策不仅受外部刺激影响，也受内部情感状态影响。近期可解释性工作表明，LLM 残差流中编码着**线性、可因果影响行为的情感表征**，但此前仅用于事后分析或输出引导，未用于智能体决策。
- **整体含义**：论文提出并验证了将 LLM 内部情感表征作为**决策级信号**来增强技能选择与技能演化的可行性，从而将情感向量的用途从可解释性扩展到智能体编排系统。

## 2. 方法论

### 2.1 核心思想

- 在每一决策步，从 LLM 残差流中提取 **27 维情感状态**（对应 GoEmotions 分类体系），将其映射为**自然语言情感模板 + 置信度分数**，在置信度足够高时注入技能选择提示。
- 在技能演化阶段，分析整条轨迹的情感状态**突变点**，定位有问题的技能调用片段，生成结构化诊断信息，指导 LLM 重写对应技能的 SOP，替代传统仅依赖二元任务结果的粗粒度信号。

### 2.2 情感向量提取与编码

- **对比方向提取**：
  - 对 K=27 个情感概念，每个概念生成 N=100 个短故事，前向传播得到残差流激活。
  - 对 token 位置 \(t \ge 50\) 做均值池化，计算类内均值与全局均值之差，得到情感方向 \(v_k^{(\ell)}\)。
  - 使用基于中性激活的 PCA 投影去除风格性方差，得到去噪方向 \(\hat{v}_k^{(\ell)}\)。
  - 最优提取层 \(L^*\) 在验证集上通过 GoEmotions 分类准确率选择（Qwen3-8B 为第 24 层，Qwen3-14B 为第 26 层）。
- **在线情感状态**：将残差流在 Assistant 分隔符位置的激活投影到情感方向矩阵 \(W_e\)，进行 \(\ell_2\) 归一化，得到 27 维向量 \(e_t\)。
- **情感编码器 \(f_\theta\)**：
  - 3 层 MLP（27→64→128→128，约 27K 参数）。
  - 输出编码表示 \(r_t\)，再派生：
    - **模板索引**：从 12 个可学习原型中选择余弦相似度最高的自然语言情感模板 \(T_t^*\)。
    - **置信度分数** \(c_t = \sigma(w_c^\top r_t + b_c) \in [0,1]\)。
  - 训练目标：有监督对比损失（聚类相同有效技能分配）+ 模板分类损失（基于 k-means 伪标签），总损失 \(L = L_{ctr} + \lambda L_{cls}\)。

### 2.3 情感增强的技能选择

- 构造增强提示 \(P_t\)：当置信度 \(c_t \ge \tau\) 时，在任务描述、历史、观察和技能 SOP 之外追加情感模板 \(T_t^*\) 和置信度 \(c_t\)；否则退化为纯文本提示。
- 技能决策通过约束生成在合法技能标识符上取最大条件概率：  
  \(s_t^* = \arg\max_{s_i \in S} p_M(s_i \mid P_t)\)。
- 超参数 \(\tau = 0.3\)（在 WebShop 验证集上调优）。

### 2.4 情感驱动的技能演化

- 对已完成轨迹的情感序列 \(E = (e_1, \dots, e_T)\)，计算逐步余弦距离：
  \[
  \delta_t = 1 - \frac{e_t^\top e_{t-1}}{\|e_t\|\, \|e_{t-1}\|}
  \]
- 当 \(\delta_t > \bar{\delta} + \sigma_{\delta}\) 时，标记为**情感过渡点** \(P\)，表示内部状态发生突变。
- 对每个被标记为表现不佳（成功率 \(< \eta\)）的技能 \(s_i\)，提取其专属过渡点 \(P_i\)，围绕每个过渡点构造 3 步诊断窗口 \(d_t\)（包含观察、技能选择、情感模板和突变幅值）。
- 将诊断上下文与口头化总结 \(\Delta_i\) 一起注入演化提示，由 LLM 改写 SOP：
  \[
  D_i' = M(P^{(i)}_{evo})
  \]
- 演化共进行 \(R=3\) 轮，每轮执行一批 episode 后更新技能库。

## 6. 主要结论与发现

- Emotion2Skill 在 **WebShop 和 ALFWorld** 上均大幅超越所有基线：
  - Qwen3-8B：WebShop 成功率 +26.9%，ALFWorld 平均成功率 +25.5%。
  - Qwen3-14B：分别 +21.3% 和 +28.9%。
- **情感向量编码了决策相关信息**，且这些信息无法从纯文本特征中获得。
- **性能提升集中在高不确定性、需要错误恢复的任务**（如 ALFWorld Heat 从 9.6% 提升至 56.9%，Pick2 从 4.4% 提升至 31.3%）。
- **情感—技能共激活**呈现语义一致的模式（如 curiosity+desire→ProductSearch；confusion+nervousness→QueryRephrase）。
- **跨域泛化**：在 MATH 和 MBPP 上复用相同情感向量也获得显著提升，表明情感信号具有领域无关的决策不确定性表征能力。
- **消融实验**证明情感提取、编码器和情感驱动演化三个组件均不可或缺，且置信度门控提供稳定路由优势。

## 7. 优点

- **新颖性**：首次将 LLM 内部情感表征用于智能体技能选择与演化，区别于以往仅用于可解释性或输出引导的工作。

- **轻量高效**：情感编码器参数量小（<27K），训练时间短（<10 分钟），易于集成。
- **全面的实验验证**：包含主结果、消融、敏感性、可解释性、跨域泛化和案例分析，证据充分。
- **可解释性突出**：情感—技能共激活热图和语义一致性分析显示模型学习到的映射具有可解释意义，而不仅是统计相关性。

## 8. 不足与局限

- **白盒访问依赖**：需要直接访问 LLM 残差流，无法直接应用于 API 服务型黑盒模型。
- **预热数据需求**：情感编码器训练需要收集约 500 个 episode 的 warm-up 数据（尽管时间短，但增加流程复杂度）。
- **基准覆盖有限**：
  - 仅使用 WebShop 和 ALFWorld 两个主要交互基准，外推实验也只用了 MATH 和 MBPP，尚缺乏更复杂的开放式环境验证。
  - 未与其他同期技能学习方法（如 ARISE、OPID、Skill-R1、ReSkill、MAGE）进行直接对比，声称与它们互补但未组合验证。
- **任务类型偏差**：在 ALFWorld Cool 等具有高度固定动作序列的任务上，Emotion2Skill 被 MASA 超越，说明情感路由并非普遍最优。
- **指令微调模型兼容性差**：如 Qwen3-8B-Instruct 的 GoEmotions 分类准确率明显低于基础模型（28.1% vs 37.2%），需要重新提取情感方向。
- **演化诊断可能过于简化**：情感过渡点检测基于单 episode 的均值和标准差，阈值机制较简单，可能受噪声影响。
- **多智能体扩展未涉及**：当前框架仅适用于单智能体技能库，未来可探索多智能体协同场景。
