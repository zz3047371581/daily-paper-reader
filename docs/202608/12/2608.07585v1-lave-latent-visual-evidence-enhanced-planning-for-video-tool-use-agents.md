## 摘要
长视频理解要求模型从冗长且冗余的视频流中高效获取并复用稀疏的视觉证据。近期的视频工具使用智能体通过在不同时间尺度上迭代调用视觉工具来应对这一挑战，但其工具-规划器之间的通信通常依赖文本观察。这种纯文本接口提供了工具计算的有损摘要，导致先前计算但未被文字化的视觉证据被丢弃，无法用于后续规划。我们将这一局限称为工具观察瓶颈，并提出潜在视觉证据增强规划（LAVE），一个无需训练的框架，用于复用已完成工具调用中的潜在视觉证据。LAVE引入了双通道观察接口：可见通道保留原始文本轨迹，而潜在通道存储带有工具角色、源帧时间戳和视觉位置的预语言化视觉更新。在规划过程中，LAVE检索与当前规划器状态相关但未被文本观察覆盖的证据，并通过有界时间戳对齐的潜在更新和熵约束的帧-时间路由将其整合。这使得视频智能体能够复用现有视觉计算，无需额外训练、帧重放或修改原有的编排流程。在Video-MME、LongVideoBench和CG-Bench上的大量实验表明，LAVE能一致地提升各种骨干网络上的视频工具使用智能体。在相当的帧预算下，LAVE将Video-MME综合得分比最强基线提高了3.76分，证明了潜在视觉证据复用在多步视频智能体规划中的有效性。

## Abstract
Long-video understanding requires models to efficiently acquire and reuse sparse visual evidence from long and redundant video streams. Recent video tool-use agents address this challenge by iteratively invoking visual Tools at different temporal scales, but their Tool-Planner communication typically relies on textual observations. Such text-only interfaces provide lossy summaries of Tool computations, causing previously computed visual evidence not verbalized to be discarded and unavailable for subsequent planning. We identify this limitation as the Tool observation bottleneck and propose Latent Visual Evidence-Enhanced Planning (LAVE), a training-free framework for reusing latent visual evidence from completed Tool calls. LAVE introduces a dual-channel observation interface: the visible channel preserves the original textual trajectory, while the latent channel stores pre-verbal visual updates with their Tool roles, source-frame timestamps, and visual locations. During planning, LAVE retrieves evidence relevant to the current Planner state but not covered by textual observations, and integrates it through bounded timestamp-aligned latent updates with entropy-constrained frame-time routing. This enables video agents to reuse existing visual computation without additional training, frame replay, or modifications to the original orchestration. Extensive experiments on Video-MME, LongVideoBench, and CG-Bench show that LAVE consistently improves video tool-use agents across backbones. Under a comparable frame budget, LAVE improves the Video-MME overall score by 3.76 points over the strongest baseline, demonstrating the effectiveness of latent visual evidence reuse for multi-step video-agent planning.

- 研究背景：长视频理解需要从冗长、冗余的视频流中定位并复用稀疏的、与答案相关的视觉证据。
- 现有范式：近期视频工具使用智能体通过迭代调用视觉工具（如 Overview、Skim、Focus）在不同时间尺度上获取证据，但工具与规划器之间通常只传递**文本观察**。
- 核心问题：文本观察是对工具计算的有损摘要，大量未被文字化的视觉证据在工具调用结束后被直接丢弃，无法用于后续规划。论文将这一现象称为**工具观察瓶颈（Tool observation bottleneck）**。
- 整体含义：论文提出 LAVE，旨在在不增加训练、不重放视频帧、不改变原有智能体编排的前提下，让智能体在后续规划中**复用已完成工具调用中产生的潜在视觉证据**，从而提升多步视频智能体的规划能力。

## 2. 方法论

- 核心思想：引入**双通道观察接口**。
  - 可见通道：保留原始文本轨迹，维持智能体原有行为。
  - 潜在通道：存储工具前向传播中、文本生成之前的视觉隐状态更新，并附带来源溯源信息。

- 关键技术细节：
  - **预语言化视觉证据获取**：在 Tool VLM 的某一 decoder block \(\ell\) 处，对视觉 token \(n\) 提取：
    - key \(k_{in} = H^{(\ell)}_{i,\text{out}}[n]\)：该 block 输出状态，用于相关性匹配。
    - value \(v_{in} = H^{(\ell)}_{i,\text{out}}[n] - H^{(\ell)}_{i,\text{in}}[n]\)：该 block 引入的局部视觉更新，避免重复传输已有信息。
  - **来源溯源与记忆**：每个证据组成三元组 \(e_{in}=(k_{in}, v_{in}, a_{in})\)，其中地址 \(a_{in}=(\tau_{in}, \xi_{in})\) 记录源帧时间戳和视觉 patch 位置，同时保留工具角色（Overview/Skim/Focus）。
  - **证据选择**：
    - 使用当前 Planner 最后一个 token 的隐藏状态 \(q_t\) 作为查询。
    - 计算源时间相关性 \(r_{tin}=\cos(q_t,k_{in})\)。
    - 通过文本冗余惩罚计算效用：\(u_{tin}=r_{tin}-\lambda[\max_{o\in O_i^{(\ell)}}\cos(k_{in},o)]_+\)，优先选择相关但未被文本充分表达的视觉证据。
    - 按源时间分组，取组内 top-4 效用的均值作为组得分，再经温度 softmax 得到源时间分布 \(p_t\)。
    - 用香农熵 \(H(p_t)\) 自适应决定保留多少个时间组：\(\log|J|\le H(p_t)\)。熵低时聚焦少数关键时刻，熵高时覆盖多个候选时刻。
  - **有界残差注入**：
    - 对每个保留组，按效用加权聚合 value，得到组残差 \(\bar{v}_{tj}\)。
    - 通过 RMS 匹配将残差缩放到当前 Planner 状态尺度，并用全局 Bound 限制累计注入幅度。
    - 在 Planner prefill 阶段，将每个残差写入对应时间戳文本行的最后一个 token 的隐藏状态，实现时间对齐；相同接收位置的残差累加。
    - 注入仅作用于规划步骤，不用于最终答案生成。

## 7. 优点

- **训练无关、即插即用**：无需参数更新，可叠加在现有视频工具智能体上。
- **双通道设计**：同时保留文本轨迹和潜在视觉证据，兼容原有可见行为。
- **避免帧重放**：不进行二次视觉编码，节省推理成本，不增加帧预算。
- **时间溯源与熵约束路由**：能动态平衡聚焦与广覆盖，提高证据选择精度。
- **有界注入**：通过 RMS 匹配和全局 Bound 限制潜在更新幅度，减少对规划器的干扰。
- **规划阶段专用**：最终答案生成不使用潜在证据，保证改进来自更优的证据获取与工具探索。
- **实验控制严格**：no-latent 对照、多骨干、多基准、消融和案例相互印证，结论可靠。

## 8. 不足与局限

- **依赖模型内部激活**：需要访问 Tool 和 Planner 的中间隐藏状态，无法直接应用于闭源 API 模型。
- **对时间戳文本有严格依赖**：要求观察中存在可解析的时间戳行，无法解析时会跳过证据，可能限制在真实自由文本工具输出上的适用性。
- **推理开销未量化**：存储隐状态和动态路由会引入额外的内存与延迟，论文未给出具体测量。
- **评测场景偏窄**：主要基于多选视频 QA，缺少开放生成、真实世界长视频任务或不同工具流程的验证。
- **超参数敏感性**：证据 token 数、残差增益、时间覆盖方式等需要调节，最佳设置可能依赖骨干网络和任务。
- **仅验证开源模型**：尚未在更大规模或不同结构的模型上进行测试，泛化性仍需进一步验证。
- **过程级案例证据有限**：案例主要证明行为变化，定量结论仍依赖主实验。
