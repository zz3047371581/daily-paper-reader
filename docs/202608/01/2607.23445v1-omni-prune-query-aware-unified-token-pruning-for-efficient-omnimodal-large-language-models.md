## 摘要
全模态大语言模型（OmniLLMs）正迅速将多模态推理扩展到同步音视频领域。然而，由此产生的音频-视频令牌序列较长，导致预填充延迟高、推理时GPU内存占用大。现有令牌剪枝方法主要针对纯视觉输入设计，既忽略了音频与视频之间的跨模态关联，也忽略了决定内容重要性的用户查询。为弥补这一不足，我们提出了Omni-Prune，一种无需训练、查询感知的音视频令牌剪枝框架，它联合去除两种模态中的冗余，同时保留与任务相关的跨模态证据。具体而言，Omni-Prune首先将令牌序列分割为自适应时间窗口，这些窗口置于音频显著峰位置，然后在一个结合编码器注意力与文本查询相关性的统一尺度上对音频和视频令牌评分，并将相关的音视频令牌配对以保持其一致性。在每个窗口内，最后的K-medoids步骤选择出少数代表性令牌，补充了仅基于评分的选择可能遗漏的多样化线索。大量实验表明，Omni-Prune优于现有基线方法，实现了高达3.25倍的预填充加速和1.3倍的内存降低，同时保留了全模型性能的99%以上。

## Abstract
Omnimodal large language models (OmniLLMs) are rapidly extending multimodal reasoning to cover synchronized audio and video. However, the resulting audio-video token sequences are long, leading to high prefill latency and GPU memory usage at inference time. Existing token pruning methods, designed mainly for vision-only inputs, miss both the cross-modal links between audio and video and the user query that decides which content matters. To bridge this gap, we present Omni-Prune, a training-free, query-aware audio-visual token pruning framework that jointly removes redundancy from both modalities while keeping task-relevant cross-modal evidence. Specifically, Omni-Prune first splits the token sequence into adaptive time windows placed at audio saliency peaks, then scores audio and video tokens on a single scale that combines encoder attention with text-query relevance, and pairs related audio-video tokens so that they are kept together. Within each window, a final K-medoids step then selects a few representative tokens, adding diverse cues that score-based selection alone would miss. Extensive experiments demonstrate that Omni-Prune outperforms established baseline methods, delivering up to 3.25x prefill speedup and 1.3x memory reduction while retaining over 99% of full-model performance.

### 2. 论文提出的方法论

Omni-Prune是一个无需训练、即插即用的框架，其核心思想与关键技术细节如下：

-   **核心思想：** 利用音频事件作为时序锚点来分割内容，然后在一个统一的评分框架内，结合编码器显著性和文本查询相关性来评估每个令牌的重要性，并通过配对机制和多样性恢复来保留关键的跨模态证据。

-   **关键技术细节与算法流程：**
    1.  **音频锚点自适应窗口划分 (Audio-Anchor Adaptive Windowing, AAW)：**
        -   **动机：** 语义事件在时间上分布不均，固定窗口会割裂连贯事件。
        -   **流程：** 首先计算每个视频帧对应音频段的平均编码器注意力作为“音频显著性”。然后，通过峰值检测找到显著性局部最大值，并以此为边界，将整个音视频令牌序列分割为内容自适应的时序窗口。

    2.  **跨模态关系图 (Cross-Modal Relation Map, CMRM)：**
        -   **动机：** 需在统一尺度下评估跨模态令牌的重要性，并保留语义相关的声音-画面令牌对，防止因独立剪枝破坏跨模态证据。
        -   **统一评分机制：**
            -   **编码器显著性 (Encoder Saliency, vi):** 提取编码器最后一层的自注意力分数，并在窗口内对音视频令牌联合进行最小-最大归一化，使其处于同一（0，1）尺度。
            -   **文本查询相关性 (Text-Query Relevance, rtext i):** 计算每个多模态令牌嵌入与用户查询文本令牌嵌入之间的余弦相似度，并缩放到（0，1）区间。
            -   **最终组合分数 (ϕi) = vi + rtext i。**
        -   **跨模态耦合：** 在窗口内计算音频和视频令牌的余弦相似度矩阵。对未直接入选的高分令牌，通过双向贪心匹配算法，将相似度超过阈值γ的音视频令牌对联合保留，确保跨模态一致性。
        -   **预算分配：** 每个窗口内，高分候选集（Kw）的数量由保留比例系数ρkeep控制，为后续的配对和多样性恢复预留预算。

    3.  **保留多样性的聚类 (Diversity-Preserving Clustering)：**
        -   **动机：** 评分阶段可能只聚焦于主体事件，丢弃了能提供互补细节（如背景环境、外围线索）的低分令牌。
        -   **流程：** 对于窗口内未选中的令牌，独立地对每种模态应用K-medoids聚类。选择一小部分比例（ρc）的“中心点（medoid）”令牌添加回保留集。该方法选择的是真实存在的令牌（而非聚类的均值向量），确保了添加到下游LLM的令牌仍在分布内，以此来最大化表征多样性。
