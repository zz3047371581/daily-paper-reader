## 摘要
长视频理解日益依赖大型视觉语言模型和工具增强的推理，但大多数系统对所有样本采用相同的推理过程，而不考虑难度。这种统一策略对简单问题会触发不必要的工具辅助处理，且在面对需要细粒度时间证据的困难问题时提供的控制有限。我们提出了 CADER（Confidence-Aware Dynamic Evidence Reasoning，置信度感知动态证据推理），一个无需训练的框架，用于自适应且可靠的长视频推理。CADER 首先对均匀采样的帧进行全局推理，并通过 logit 边际信号估计答案置信度，使高置信度样本能够提前退出。对于不确定的样本，CADER 会启动第二阶段工具增强循环，结合时间裁剪、轻量级语义验证和相关性引导重采样，逐步定位与问题相关的证据。这种设计将工具使用视为样本级别的决策：单次全局传递即可处理简单情况，而为不确定性表明需要更多证据的样本保留额外的推理。在多个视频问答基准上的实验表明，CADER 在提升长视频推理能力的同时，能够绕过第二阶段处理高置信度样本。此外，当应用于仅在无工具链式思维监督下训练的骨干网络时，CADER 在与专门的工具增强框架对比中取得了有竞争力的表现，这为自适应长视频推理提供了一条实用的推理时路径。

## Abstract
Long-video understanding increasingly relies on large vision-language models and tool-augmented reasoning, but most systems apply the same inference procedure to every example regardless of difficulty. This uniform strategy invokes unnecessary tool-assisted processing for easy questions and provides limited control when difficult questions require fine-grained temporal evidence. We propose CADER (Confidence-Aware Dynamic Evidence Reasoning), a training-free framework for adaptive and reliable long-video reasoning. CADER first performs global reasoning over uniformly sampled frames and estimates answer confidence with a logit-margin signal, allowing high-confidence examples to exit early. For uncertain examples, CADER activates a second-stage tool-augmented loop that combines temporal cropping, lightweight semantic verification, and Relevance-Guided Resampling to progressively localize question-relevant evidence. This design treats tool use as a sample-level decision: a single global pass handles easy cases, while additional reasoning is reserved for examples where uncertainty suggests that more evidence is needed. Experiments on multiple VideoQA benchmarks show that CADER improves long-video reasoning while bypassing Stage~2 for high-confidence samples. Moreover, when applied to a backbone trained only with tool-free chain-of-thought supervision, CADER achieves competitive performance against specialized tool-augmented frameworks, suggesting a practical inference-time route for adaptive long-video reasoning.

### 2. 论文提出的方法论

论文提出了 **CADER (Confidence-Aware Dynamic Evidence Reasoning)**，一个无需训练的推理时框架。其核心思想是“先全局后局部，先信心后搜寻”，由两个阶段构成：

*   **核心思想**：
    *   **样本级自适应路由**：通过模型自身的置信度信号来决定一个样本是需要简单的全局推理，还是需要进入昂贵的工具调用阶段。
    *   **闭环证据精炼**：对于困难样本，设计了一个结合时间定位、轻量级验证和动态重采样的闭环，以减少无关证据和错误累积。

*   **关键技术细节与流程**：
    1.  **阶段一：全局初步推理**
        *   **帧采样**：对视频进行统一采样（如 1.0 fps），获取全局视角帧序列。
        *   **置信度估计**：主模型（Qwen3-VL-8B）对候选答案生成 logits，通过一个**带温度系数 T=2.0 的 Softmax** 计算概率分布，并计算 **Logit 边际 (logit margin)** M = P_top1 - P_top2。M 越大，代表模型对自己的答案越确信。
        *   **提前退出机制**：若 M 大于一个高阈值 τ=0.97，系统直接将 Top-1 选项作为最终答案输出，**完全跳过第二阶段**。此阶段禁用思维链以节省算力。

    2.  **阶段二：工具辅助的细粒度推理**
        *   仅当 M < τ 时，样本进入此阶段，这是一个最多包含 K=2 轮反思的迭代过程。
        *   **时间片段提议**：主模型被提示以“接地”的方式，根据问题定位出一个可能包含关键证据的时间区间 [t_s, t_e]。若提议区间过长（超过1200秒或视频时长的20%），则回退到阶段一的答案。
        *   **局部证据验证**：根据提议裁剪视频，并使用一个**轻量级的 VLM (Qwen3-VL-4B)** 作为语义验证器。验证器以更高的帧率（预算感知采样，r2 up to 8.0 fps）审查该片段，回答该片段是否包含回答问题所需的证据，并输出“是”的概率 P_yes。
        *   **反思式时间搜索**：若 P_yes < δ=0.60（即证据不充分），系统进入反思。会将之前失败的区间告知主模型，让其**排除已探索区域，提出新的、不重叠的区间**。
        *   **相关性引导的重采样 (RGR)**：这是该方法的一个关键创新。在反思阶段，不是对整个视频进行均匀采样，而是根据历史上验证器对各个片段的 P_yes 评分，构建一个**动态帧率地图**。已验证为低相关性的区域以较低的帧率（如 0.4 fps）重采样，而未被探索过的区域保持基础帧率。**这实质上是将搜索历史编码为视觉信号的密度**，既节省了上下文 token，又引导了下一轮提议。
        *   **最终局部推理**：一旦某个提议片段被验证器接受，主模型将对该片段进行高帧率推理，并输出最终答案。如果迭代预算耗尽仍未找到有效片段，则回退到阶段一的答案。

### 8. 不足与局限

*   **超参数依赖**：框架引入了多个手工设置的阈值，如置信度阈值 τ=0.97、验证器阈值 δ=0.60。这些固定值在不同领域或分布偏移的数据上可能非最优，需要重新校准。
*   **回退机制的风险**：当第二阶段迭代用尽时，系统会回退到阶段一的预测。如果阶段一的初始预测就是错误的且置信度低（即模型“不自知的错误”），该系统可能无法修正，存在性能上限。
