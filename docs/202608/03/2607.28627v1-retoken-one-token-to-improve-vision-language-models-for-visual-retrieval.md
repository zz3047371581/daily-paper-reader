## 摘要
长视觉上下文给视觉语言模型带来了挑战：随着干扰项数量的增加，性能会下降，而在GPU内存限制下一次性处理所有令牌在计算上是不可行的。我们提出了ReToken，一个可学习的嵌入，作为显式检索目标进行训练，该目标从预填充的视觉KV缓存中选择一组稀疏的与查询相关的视觉令牌。仅在一个小型图像问答数据集上训练，ReToken在图像和视频基准测试中均取得了一致的增益：在Visual Haystacks上，它将Qwen3VL-8B提升了13.4点，InternVL3.5提升了12.4点（相对提升超过20%）；在LVBench上，它以零样本方式迁移到长视频，为Qwen3VL-8B带来了8.0点的增益。得益于其轻量级设计，训练和长视频推理均可在单个H100上完成。代码见：https://github.com/avaxiao/ReToken

## Abstract
Long visual context poses a challenge for vision-language models: performance degrades as the number of distractors grows, and processing all tokens at once is computationally infeasible under GPU memory constraints. We present ReToken, a single learnable embedding trained as an explicit retrieval target that selects a sparse set of query-relevant visual tokens from a pre-filled visual KV cache. Trained on only a small image-QA dataset, ReToken yields consistent gains across image and video benchmarks: on Visual Haystacks it improves Qwen3VL-8B by 13.4 points and InternVL3.5 by 12.4 points (>20% relative), and on LVBench it transfers zero-shot to long video for an 8.0-point gain with Qwen3VL-8B. Thanks to its lightweight design, both training and long-video inference fit on a single H100. Code is available at: https://github.com/avaxiao/ReToken

### 1. 论文的核心问题与整体含义
- **研究背景**：视觉语言模型在处理长视觉上下文（如大量图像集合或超长视频）时面临两大挑战：
  - 性能随干扰项增多而急剧下降。
  - 一次性处理全部视觉 token 会超出 GPU 显存限制。
- **核心问题**：如何从长视觉上下文中精确检索出与查询相关的少量帧或 token，以支撑模型生成正确答案。
- **关键发现**：预训练 VLM 内部的注意力（query-key）信号与视觉相关性关联很弱，不宜直接用作检索依据；而视觉 token 的 **value 投影** 与文本之间的对齐信号更强，但前提是需要一个精确的检索目标（而非对问句 token 进行简单平均）。由此提出 ReToken。

### 2. 论文提出的方法论
- **核心思想**：在问题后追加一个 **可学习的检索 token（ReToken）**，将其训练为显式的检索目标，从其输出与帧的平均 value 向量的余弦相似度得到检索分数。
- **关键技术细节**：
  - **检索分数计算**：在最终层 \(L_N\)，对每一帧 \(f\) 计算其视觉 token 的均值 value 向量 \(\bar{v}_f^{(N)}\)，将 ReToken 的输出经一个可学习投影矩阵 \(W_r\) 变换得到 \(Z_r\)，以余弦相似度 \(\cos(Z_r, \bar{v}_f^{(N)})\) 作为该帧的检索得分。
  - **训练过程**：默认冻结整个 VLM，仅训练 ReToken 嵌入 \(X_r\) 和投影矩阵 \(W_r\)。使用类别平衡的二元交叉熵损失，对地面真值相关/不相关帧进行监督。也可选择部分微调 VLM 的前几层，此时加入生成损失以保持问答能力。训练数据为经筛选的多图像问答数据集（MIRAGE）。
  - **推理流程**：采用两步法。第一步：输入视频一次性编码并缓存 KV，然后对问题执行一次前向传播（早期层通过相似度快速定位至多 \(K_1\) 帧以节省显存），在最后一层得到 top-K 帧索引。第二步：仅加载这 K 帧的 KV 缓存，生成最终答案。
- **关键公式**（文字说明）：
  - 帧级均值 value：\(\bar{v}_f^{(N)} = \frac{1}{|I_f^v|} \sum_{i \in I_f^v} v_i^{(N)}\)。
  - 投影后 token：\(Z_r = W_r X_r^{(N)}\)。
  - 得分：\(s_f^{(N)} = \cos(Z_r, \bar{v}_f^{(N)})\)。
  - 损失：\(L_{\text{ret}} = -\frac{1}{|F^+|}\sum_{f \in F^+} \log \sigma(\tau s_f) - \frac{1}{|F^-|}\sum_{f \in F^-} \log \sigma(-\tau s_f)\)。

- **评估基准与场景**：
  - **Visual Haystacks**：单针检索任务，需从 \(C\) 张图中找出唯一相关图像，回答“是/否”。

  - **Video-MME**：多时长视频（短/中/长），进一步验证时长对检索增益的影响。
- **对比方法**：

  - 外部检索器 SigLIP2。
  - 注意力检索方法 ReKV（query-key 打分）。
  - 链式思维检索（CoT + ReKV）。
  - 专用多图像 RAG 框架 MIRAGE。
  - 统一采样（无检索）。
  - 上限：使用真实相关帧的 KV 缓存（GT Cache）。

### 4. 资源与算力
- **训练**：单张 H100 GPU。Qwen3VL-8B 冻结模式训练 3 个 epoch，部分微调约 4 小时。InternVL3.5-8B 仅训练 1 个 epoch。
- **推理**：长视频推理同样在单张 H100 上完成，视频编码一次性完成（约 14.7 秒/视频），每问题检索和回答延迟增加约 0.4 秒。

### 5. 实验数量与充分性
- **实验组数丰富**：

  - 在两个骨干模型（Qwen3VL、InternVL3.5）上验证，包含冻结与部分微调设定。
  - 三个视频基准（QAEgo4D、LVBench、Video-MME）上的零样本迁移实验。
  - 大量消融实验：key vs. value 空间、训练仅调 token vs. 部分微调、单 pass vs. 双 pass 推理、ReToken 是否允许注意图像、多 token 设计、训练数据过滤影响、推理延迟与内存分析、按问题类型的错误分析（共 11 组以上的控制实验）。
- **充分性与公平性**：实验设计全面，覆盖了检索能力、下游任务精度、零样本泛化、效率以及局限性。对比基线包含当前主流的检索和无检索方案，对照组设置合理，消融论证清晰。训练数据仅为图像 QA，却能在长视频上取得显著提升，说明方法泛化性较好，实验客观严谨。

### 6. 论文的主要结论与发现
- **Value 空间优于 Key 空间**：在 VLM 中，用于视觉检索的最佳信号来自 value 投影而非 query-key 注意力得分，但需要一个精确的检索目标，否则平均值池化会引入噪声。
- **ReToken 高效且有效**：仅需一个可学习 token 和少量参数，冻结 VLM 即可在图像检索基准上大幅提升（Qwen3VL 在 50 张图片中提升 13.4 点），在超长视频 LVBench 上零样本迁移提升 8.0 点。
- **图像到视频的零样本迁移**：即使只在图像数据上训练检索 token，也能迁移到长视频场景，且视频时长越长，检索带来的增益越大。
- **局限性分析**：当问题需要总结全片或依赖跨帧时序推理时，检索式方法不如均匀采样。

### 7. 优点
- **诊断性贡献**：清晰地揭示了预训练 VLM 中注意力信号对视觉检索的不可靠性，并验证了 value 空间的优越性。
- **方法简洁轻量**：仅引入一个 token 和一个投影矩阵，训练和推理均在单 H100 上完成，极大降低了应用门槛。
- **强泛化能力**：图像数据训练的检索 token 可直接零样本应用于长视频检索，体现了模型对“查询-内容匹配”本质的捕捉。
- **实验设计周密**：从静态图像到长视频，从冻结到微调，从精度到效率，提供了全面的消融和错误分析。

### 8. 不足与局限
- **推理开销**：需两遍前向传播，且早期层需注意更多视觉上下文，带来轻微的延迟和显存增加。
- **训练数据域偏差**：训练仅采用多图像 QA 数据，缺乏视频时序和动态信息的训练，可能限制了在需要跨帧时序推理任务上的性能。
- **任务适配性**：在“摘要”等需要融合全局信息的任务上表现下降，因为检索可能丢弃了部分必要背景帧。
- **检索粒度**：当前基于帧级均值池化，可能遗漏仅占据少量 token 的细粒度视觉证据。
- **评估局限**：视频评估主要依赖选择题形式的基准（LVBench, Video-MME），对开放式生成任务的实际影响未充分探索。
