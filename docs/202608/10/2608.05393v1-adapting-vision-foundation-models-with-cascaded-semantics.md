## 摘要
提示调优是自然语言处理中领先的参数高效适应范式，最近已扩展到计算机视觉。视觉提示调优（VPT）通过更新少量额外的提示参数来适应预训练的视觉Transformer（ViT）。然而，现有的视觉提示是随机初始化的，并未利用先验知识，如自然语言处理中的指令。我们通过向VPT注入两个互补的语义先验来解决这一差距。基本的图像先验，包括颜色、纹理和形状，通过经典的、手工设计的算子提取并注入输入空间，而自注意力图在特征空间中提供实例感知的语义。我们进一步提出一种级联方案，将这两种先验集成到整个ViT适应过程中。在34个具有挑战性的图像分类数据集上的实验表明，仅调整0.74%的ViT参数即可实现优异的下游适应。项目页面：https://xixiaouab.github.io/Cascaded-Semantics/。

## Abstract
Prompt tuning, a leading parameter-efficient adaptation paradigm in NLP, has recently been extended to computer vision. Visual prompt tuning (VPT) adapts pre-trained vision transformers (ViTs) by updating a small set of additional prompt parameters. However, existing visual prompts are randomly initialized and do not exploit prior knowledge, such as instructions in NLP. We address this gap by injecting two complementary semantic priors into VPT. Fundamental image priors, including color, texture, and shape, are extracted with classical hand-crafted operators and injected into the input space, while self-attention maps provide instance-aware semantics in the feature space. We further propose a cascaded scheme that integrates both priors throughout ViT adaptation. Experiments on 34 challenging image classification datasets demonstrate superior downstream adaptation while tuning only 0.74% of ViT parameters. Project page: https://xixiaouab.github.io/Cascaded-Semantics/.

### 2. 论文提出的方法论

- **核心思想**: 注入两种互补的语义信息作为“硬提示”（non-learnable prompts），并与原有的“软提示”（learnable prompts）结合，通过级联设计贯穿整个ViT网络，为随机初始化的可学习提示提供有意义的语义“锚点”，指导其优化方向。

- **关键技术细节与流程**:

  - **输入空间：基础图像先验提示**:
    - 从原始输入图像`X`（而非深层特征）中，利用经典的、无学习的手工算子提取三种人类可理解的先验知识：
      - **颜色** (`σc(X)`): HSV颜色直方图。
      - **纹理** (`σt(X)`): Gabor滤波器响应。
      - **形状** (`σs(X)`): Sobel边缘检测算子。
    - 将这三种固定（non-learnable）的先验特征与随机初始化的可学习提示`P1`拼接，形成一个包含语义信息的输入空间提示`˜P1`。
    - `˜P1 = P1 ⊗ FC(σc(X) ⊗ σt(X) ⊗ σs(X))`，其中`FC`为调整维度的单层线性层。

  - **特征空间：实例感知的注意力语义提示与级联设计**:
    - **实例感知提示**: 对于第`i`层Transformer，计算其自注意力图`Ai`，它反映了该层感知到的、与决策相关的实例级语义。将`Ai`作为固定语义提示，与当前层的可学习提示`Pi`拼接：`FC_i(Ai) ⊗ Pi`。
    - **级联方案 (Cascaded Scheme)**: 通过**跳跃连接**，将前一层`i-1`的提示`Pi-1`和自注意力图`Ai-1`也传递到第`i`层，形成最终的层级提示：
      `˜Pi = FC_i(Ai) ⊗ Pi ⊗ FC_{i-1}(A_{i-1}) ⊗ P_{i-1}`
    - 这使得当前层获得了来自前面层的、逐步累积的语义信息，实现了语义的级联流动。

  - **重加权适配器**: 在最终特征输入分类头之前，引入一个轻量级的“FC-Softmax-FC”模块，对特征通道进行重加权，以增强特征适应性。

- **关键论证**: 论文通过在CUB-200数据集上的消融实验（图3）论证了“并非参数越多越好”，增加FC层数、提示长度、适配器宽度等反而可能损害性能或收益递减，证明了其设计中参数放置位置和方式的重要性。
