## 摘要
视频大语言模型（Video-LLMs）在开放式视频理解方面取得了显著进展。然而，它们的视觉接口仍然消耗大量令牌，并且在连接跨时间的重复对象证据方面提供的显式结构有限。我们提出了SlotNarrative，一个基于槽的接口，它将视频组织为紧凑的对象状态令牌表示的持久对象叙述。SlotNarrative不是在建立时间对应关系之前压缩逐帧特征，而是首先将视觉特征分组为类似对象的槽，然后通过一个轻量级、无参数的内存将重复观测与片段级别的对象条目关联起来，该内存集成了多个互补的匹配线索。每个保留的条目被序列化为两种令牌类型：一种身份令牌，总结持久对象外观；一组状态令牌，编码片段级外观、几何形状、可见性和轨迹信息。这种设计为冻结的Video-LLM产生了一个仅分配144个视觉令牌位置的接口，与采样的帧数无关。在多个数据集上，与先前的紧凑Video-LLM接口相比，SlotNarrative在准确性和视觉令牌数量之间取得了有利的权衡。实验结果确立了持久对象叙述作为Video-LLMs的紧凑、结构化且时间上组织良好的视觉接口。我们的代码将公开发布。

## Abstract
Video large language models (Video-LLMs) have made strong progress in open-ended video understanding. However, their visual interfaces remain token-intensive and provide limited explicit structure for linking recurring object evidence across time. We introduce SlotNarrative, a slot-based interface that organizes a video into persistent object narratives represented by compact object-state tokens. Rather than compressing frame-wise features before establishing temporal correspondence, SlotNarrative first groups visual features into object-like slots and then associates recurring observations with clip-level object entries through a lightweight, parameter-free memory that integrates multiple complementary matching cues. Each retained entry is serialized into two token types: an identity token that summarizes persistent object appearance and a set of state tokens that encode segment-level appearance, geometry, visibility, and trajectory information. This design yields an interface of only 144 allocated visual-token positions for a frozen Video-LLM, independent of the number of sampled frames. Across multiple datasets, SlotNarrative achieves a favorable trade-off between accuracy and visual-token count compared with prior compact Video-LLM interfaces. Experimental results establish persistent object narratives as a compact, structured, and temporally organized visual interface for Video-LLMs. Our code will be made publicly available.

- **整体含义**：论文提出**将视频组织为以对象为中心的“持久对象叙述”** ，用紧凑且结构化的方式取代密集的帧级令牌，让语言模型能够更高效地理解视频中物体的持续身份和状态变化，从而在保持甚至提升准确性的同时大幅降低视觉令牌的消耗。

### 2. 方法论

#### 核心思想
论文提出了**SlotNarrative**，一种基于槽（slot）的对象中心接口。其核心在于**先进行对象分组与关联**，再**进行序列化**，而非传统的先压缩再输入LLM。

#### 关键技术细节与流程
整个框架包含三个主要阶段，如下图2所示（摘要中描述）：

1.  **对象中心编码器**：
    -   使用冻结的 **SigLIP** 提取逐帧的补丁特征。
    -   通过**循环槽注意力**（Recurrent Slot Attention）将帧特征分组为 **K=11** 个类似对象的槽。同时，利用循环初始化和预测器保证片段内对象掩码的短期一致性。
    -   为每个槽提取**观测特征**（包括空间、运动、形状统计量），并通过一个因果**轨迹编码器**将其编码为轨迹状态向量。同时，一个存在概率预测器判断槽中物体是否存在、是否可见。

2.  **持久对象记忆（Parameter-Free Memory）**：
    -   该模块将逐帧、可交换的槽观测关联到**片段级别的持久对象条目**。
    -   **无参数匹配**：当一个槽从“不可见”变为“可见”（重新出现）时，利用多个互补线索计算其与当前所有未激活条目的匹配分数。这些线索包括：槽特征相似度、池化外观相似度、轨迹状态相似度、近期观测相似度，以及基于速度预测的质心接近度。
    -   **匹配公式**：\[
        \rho_{t,k,u} = \frac{\sum_{\ell \in \mathcal{C}} w_{\ell} \gamma_{\ell}(t, k, u)}{\max(\sum_{\ell \in \mathcal{C}} w_{\ell}, \epsilon)}
        \]
        其中 \(\gamma\) 为各线索的相似度，\(w\) 为固定权重，\(\mathcal{C}\) 为所有线索的集合。
    -   采用**贪心一对一匹配**。匹配成功则恢复条目并更新其状态；未匹配的可见槽则创建新条目；条目暂时不可见时仍被保留，不参与更新。
    -   对于检测到的场景切换，重置局部运动，仅依靠外观特征进行匹配，避免将剪辑误判为极端运动。

3.  **类型化对象-状态序列化**：
    -   从所有持久条目中，根据可见时长、状态变化和对象属性得分进行排序，**选择至多 \(M=16\) 个最重要的对象**进入固定库存。
    -   对每个保留条目，生成两种类型的令牌：
        -   **身份令牌**：聚合该条目所有可见帧的注意力池化外观特征，得到一个对象外观摘要。
        -   **状态令牌**：将视频均匀划分为 \(J=8\) 个时间片段，为每个片段聚合外观、几何、可见性、轨迹状态及重识别事件，得到该片段的综合状态总结。
    -   两种令牌分别通过**独立的投影层**和**层归一化**，加上**类型、对象索引、片段索引嵌入**后，映射到语言模型的嵌入空间。
    -   **最终接口**：生成 \(M \times (1 + J) = 16 \times (1 + 8) = \mathbf{144}\) 个固定的视觉令牌位置，未使用的对象或片段位置将被掩码。这144个位置是固定的分配上限，与视频采样帧数无关。

#### 训练策略
采用**三阶段顺序训练**，每个阶段仅优化特定模块，前序模块被冻结：
-   **阶段1（对象槽表征）**：在无标签的 ActivityNet 视频片段上，使用特征重建、SlotContrast 和协同表示学习（SRL）进行训练，学习对象分组和局部一致性。
-   **阶段2（轨迹与存在性）**：冻结槽编码器，使用未来观测预测损失和基于置信度的存在/可见性监督，训练轨迹编码器和存在预测器。
-   **阶段3（语言对齐）**：冻结所有视觉模块和 Qwen2-7B-Instruct 语言模型，仅训练身份/状态投影器、层归一化和类型化嵌入，使用 VideoInstruct-100K 的指令对话数据进行训练。

### 6. 主要结论与发现

-   **有效性**：SlotNarrative 仅使用 **144 个固定的视觉令牌**，在 MSVD-QA 和 MSRVTT-QA 上取得了与高令牌消耗模型相当甚至更优的准确率，并在 ActivityNet-QA 上优于同等令牌预算的 Slot-VLM 等方法，实现了准确率与视觉令牌数量的**有利权衡**。
-   **组件价值**：
    -   **轨迹编码**和**持久记忆**各自都能带来提升，两者结合效果最佳，这表明局部状态理解和长程对象关联对于视频理解是互补的。
    -   **身份/状态令牌分解**至关重要。仅提供对象摘要或片段状态的效果都远不如其组合，证明了分离稳定外观和时间变化的必要性。
-   **表征诊断**：
    -   槽注意力能有效地对对象进行分组，但存在一定的**碎片化问题**（49%的碎片率）。
    -   **外观信息**被有效保留在池化的外观特征中，但槽向量的直接余弦相似度较弱，这验证了使用池化外观构建身份令牌的设计。
    -   **时序信号**是当前表示的一个薄弱环节，轨迹状态中几乎不包含线性可读的速度或帧序信息。

### 7. 优点

1.  **设计理念先进且高效**：从“逐帧压缩”转向“对象叙事”，提供了一种**结构化、紧凑且可解释**的视觉接口，是这个领域的重要思想贡献。
2.  **无参数记忆机制**：精巧设计的**无参数、多线索匹配**模块展现了强大的工程智慧，它在不影响下游语言对齐训练的前提下，有效地解决了跨越时间间隔的对象重识别问题。
3.  **类型化令牌分解**：将对象表征明确地分解为**身份令牌**和**状态令牌**，既保留了对象的恒常性信息，又捕获了其时间动态，这种设计针对VLLM的输入特性进行了优化。
4.  **极致的令牌效率**：将视觉令牌数量压缩至与视频长度无关的固定144个位置，极大地缓解了长视频处理中的上下文长度压力。
5.  **实验分析全面而深刻**：不仅有丰富的对比和消融，还通过线下探针分析了表征的本质，并提供了按问题类型和失败案例的细致分析，为理解模型能力和局限提供了清晰的洞察。

### 8. 不足与局限

1.  **时序信号编码能力弱**：诊断实验和失败案例均表明，模型对**精细时间顺序、事件先后关系、速度等时序信号的线性编码能力较弱**，这是区分动作和理解事件动态的关键瓶颈。
2.  **对象碎片化问题**：接近一半的槽被标记为碎片化（包含离散背景），这表明底层分组仍有提升空间，可能损失细节或导致对象被错误分裂。
3.  **依赖语言模型性能**：准确率受限于底层冻结的7B规模语言模型，面对需要复杂时间或空间推理的任务时，准确率仍显著低于整体平均（如时间、空间类问题）。
4.  **实验设定限制**：尽管对比公平，但整体性能仍低于那些依赖更大量训练数据（百万级）或更强大语言模型的模型。其性能上限在一定程度上受限于训练数据量和语言模型规模。
5.  **潜在应用风险**：无参数记忆虽然巧妙，但其固定的阈值和权重是启发式的，可能对特定场景（如极度拥挤、物体频繁遮挡）不够鲁棒，导致对象关联失败（如失败案例中的计数错误和身份混淆）。
