## 摘要
长时程基于事件的动作理解仍待探索，因为现有数据集主要包含短时修剪片段，而采集带有密集时间标注的原生事件流成本高昂。我们引入Event ActivityNet，一个源自人工标注、未修剪的ActivityNet视频的大规模模拟事件基准。它包含3263个视频、200个动作类别和106.94小时，配有匹配的5箱和9箱事件体素表示、时序动作标注以及带时间戳的字幕。该基准支持标注片段动作识别、辅助事件-语言对齐以及因果在线时序动作定位。我们直接按解码帧顺序从非插值源视频生成事件体素，保留每个视频的合理标称或平均帧率元数据用于近似时间映射，并使用动作中心重建的LPIPS作为保留可重建内容的软诊断指标。我们为自适应事件帧生成、提示-字幕对齐以及仅事件、仅RGB和RGB-事件定位建立了基线。在渐进嵌套尺度训练方案下，识别Top-1准确率从52.25提升至66.42，而在线时序定位平均mAP从21.7提升至29.0。此外，分阶段的Event ActivityNet预训练后接原生事件微调，在多种监督预算下均持续优于仅目标域训练和从头联合训练。Event ActivityNet为长时程事件建模提供了可扩展的基准，尽管原生相机评估对于面向部署的结论仍然不可或缺。

## Abstract
Long-horizon event-based action understanding remains underexplored because existing datasets largely comprise short, trimmed clips, while collecting native event streams with dense temporal annotations is costly. We introduce Event ActivityNet, a large-scale simulated-event benchmark derived from human-annotated, untrimmed ActivityNet videos. It comprises 3,263 videos, 200 action classes, and 106.94 hours, with matched 5-bin and 9-bin event-voxel representations, temporal action annotations, and timestamped captions. The benchmark supports annotated-segment action recognition, auxiliary event-language alignment, and causal online temporal action localization. We generate event voxels directly from non-interpolated source videos in decoded frame order, retain per-video rational nominal or average frame-rate metadata for approximate time mapping, and use action-center reconstruction LPIPS as a soft diagnostic of retained reconstructable content. We establish baselines for adaptive event framing, prompt-caption alignment, and event-only, RGB-only, and RGB-event localization. Under a progressive nested-scale training protocol, recognition Top-1 accuracy increases from 52.25 to 66.42, while online temporal localization average mAP improves from 21.7 to 29.0. Moreover, staged Event ActivityNet pretraining followed by native-event fine-tuning consistently outperforms target-only and joint-from-scratch training across multiple supervision budgets. Event ActivityNet provides a scalable benchmark for long-horizon event modeling, although native-camera evaluation remains essential for deployment-oriented conclusions.

* **背景**：事件相机（event camera）以异步、低延迟、高动态范围采集像素亮度变化，在高速运动、复杂光照及流式感知场景中优势显著。然而，现有事件动作理解数据集多为短时修剪片段（trimmed clips），缺乏长时、未修剪（untrimmed）视频下的事件流基准。

* **整体含义**：论文提出 **Event ActivityNet**，一个大规模**模拟事件流基准**，通过对ActivityNet v1.3未修剪RGB视频进行视频‑事件体素转换，复用现有人工标注，为未修剪事件流上的动作识别与因果在线时序定位提供可扩展且经济的测试平台。

## 2. 论文提出的方法论

### 2.1 模拟事件体素生成（视频到体素直接生成）
* **核心思路**：直接从解码帧序列生成离散事件体素，避免中间插值到高帧率（如240 Hz）或生成连续事件流，减轻伪影并降低存储开销。
* **关键步骤**：
  - 对解码的8位灰度帧计算对数强度变化，使用固定正/负阈值（0.2）累积带极性的过渡切片（transition slices）。
  - 每B个相邻帧过渡切片聚合为一个事件体素张量 `Xq ∈ ℝ^{B×H×W}`（B=5或9），相邻体素共享边界帧但不共享过渡区间。
  - 保留每个视频的原始帧率元数据（标称或平均帧率），通过帧索引→秒的近似映射实现视频级时序对齐，但不保留逐帧PTS。
* **质量控制**：对每个动作标注片段中心帧，使用HyperE2VID重建器与LPIPS（∆=0.30）进行软诊断，确保体素中保留了可重建的动作内容，但该指标不作为视频筛选规则。

### 2.2 自适应事件帧构建（AEF‑Split&Merge）
* 针对未修剪事件流中“突发运动‑静默区间”的非平稳特性，提出轻量非参数流程：
  - **分裂**：计算候选划分点两侧体素的活性率（ρ）与空间‑极性直方图（h）的差异，当差异超过高分位阈值（τ_split）时分裂，并保证子片段时长不低于d_min。
  - **合并**：对相邻片段计算相似度，低于低分位阈值（τ_merge）时合并。
  - **顺序**：先分裂至收敛，后执行一次合并，防止震荡。

### 2.3 事件‑文本对比对齐
* 在动作识别训练中，引入辅助的事件‑语言监督：
  - 使用固定文本编码器生成人工模板提示、可学习提示及匹配ActivityNet Captions描述的嵌入。
  - 构造融合类原型与匹配字幕的正样本，搭配批次内负样本（适当降权），采用温度缩放余弦相似度的对比损失。
  - 通过tIoU≥0.1匹配字幕与动作实例，弱对齐不修改原动作标签或边界。

### 2.4 因果RGB‑事件融合在线时序定位
* 基于SimOn和MATR框架，提出仅使用前缀观测的RGB‑事件融合机制：
  - **C1（事件降采样）**：将事件特征对齐到RGB帧率。
  - **C2（RGB帧复制）**：复制RGB特征至事件率。
  - **CA（因果交叉注意力）**：以事件特征为查询，RGB前缀为键/值，使用因果掩码。
* 匹配的仅RGB、仅事件控制组使用同架构、同时间戳对齐及训练调度，以公平比较模态贡献。

### 2.5 渐进嵌套尺度训练协议
* 设计固定嵌套子集：诊断集（~10h）、Small（~20h）、Medium（~50h）、Large（~107h），Large为完整的3,263个视频。
* 诊断集和Small随机初始化；Medium和Large均从相同的Small检查点独立开始训练，以研究数据规模对性能的增益。

## 6. 论文的主要结论与发现

* Event ActivityNet 提供了一个**可扩展、可审计的未修剪事件动作理解基准**，填补了长时事件流时序定位的空白。
* 所提自适应帧构建（AEF‑SM）和事件‑文本对比对齐能有效提升识别性能（Top‑1从52.25升至57.65），字幕辅助监督提供了中等但稳定的增益。
* 在在线TAL中，RGB‑事件交叉注意力融合可超越仅RGB与仅事件模型，达到25.8 Avg. mAP / 40.6 mAP@30，表明两种模态互补。
* **渐进规模**下性能持续增长：识别Top‑1从52.25→66.42，在线定位Avg. mAP从21.7→29.0，验证了更大数据量的价值。
* 5‑bin与9‑bin体素在识别上表现接近（差异≤0.21），但在因果RGB‑事件融合的定位任务中9‑bin略有优势（mAP@30提升1.8点），说明更细粒度可能利于边界敏感融合。
* 分阶段预训练+微调在多个原生事件数据集上**始终优于**仅目标域训练和联合从头训练，尤其在低数据量（10%）下增益显著（最高7.65点），表明模拟数据可有效迁移至真实事件域。

## 7. 优点

* **大规模长时未修剪事件基准**：填补了事件领域从修剪片段到长时流处理的空缺，支持复杂的因果在线定位任务。
* **原始帧率模拟与体素生成**：避免高帧率插值带来的伪影，保留原始视频动态，并提供5‑bin/9‑bin双版本用于时序离散化消融。
* **严谨的基准设计与公平对比**：固定训练计划、最终检查点汇报、匹配的模态控制组、多重随机运行，为后续研究奠定了可靠的参照点。
* **全面的基线剖析**：从自适应帧构建、多模态融合到渐进尺度、体素粒度和迁移学习，形成了系统性的实验体系，参照价值高。
* **弱监督复用人类标注**：通过tIoU匹配ActivityNet Captions，在无额外标注成本下为事件模型提供辅助语言监督。
* **诊断与质量审计**：采用重建LPIPS对动作中心进行软诊断，确保模拟体素保留了可识别的视觉内容，提升数据集可信度。

## 8. 不足与局限

* **模拟域与真实域差距**：未建模真实事件传感器的噪声、热像素、泄露、异步时间戳、高动态范围等特性，导致基准上的结论不能直接等价于真实相机场景。
* **时序映射近似**：使用标称/平均帧率映射，对于变帧率视频存在误差；模拟器每次调用重置固定随机种子，可能降低扰动多样性。
* **质量控制有限**：LPIPS仅检查动作中心，未验证完整时间边界及背景‑动作过渡的保真度。
* **数据集偏差**：从ActivityNet精筛子集，引入了类别分布偏移（相关系数约0.64），且运动/光照触发词的筛选可能偏向特定视觉模式。
* **物理传感器验证缺失**：所有基线评估基于模拟事件，未在真实事件相机录制的未修剪视频上验证在线定位与长时理解的泛化性。
* **资源门槛**：体素数据约5TB×2，加上原始视频，对研究者的存储和计算提出很高要求。
* **在线定位指标单一**：主要采用mAP系列，未涉及动作片段召回、早期检测度量等更细致的流式评价。
* **骨干网络受限**：参考模型均围绕ExACT、SimOn、MATR等固定架构适配，未探索更新的骨干或专门的长时事件Transformer设计。
