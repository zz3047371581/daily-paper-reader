## 摘要
流式视频大语言模型（Streaming VideoLLMs）以因果方式逐帧处理，同时视觉令牌数量持续增长，因此压缩对于控制预填充延迟和内存至关重要。现有的免训练方法独立地对令牌进行排序，忽略了保留令牌之间的边际增益交互。我们认为，流式视频令牌压缩应被形式化为集合选择问题，其中每个候选令牌的价值取决于它在已保留令牌之外所增加的信息。与为离线任务设计的现有集合方法不同，流式处理需要因果的、逐帧的剪枝决策，因此建模跨帧交互需要显式的历史参考。这带来了参考集困境：参考必须充分代表先前传达的内容，同时保持有界以实现实时推理。我们提出了NovaCov，据我们所知，这是首个专为流式视频设计的免训练、即插即用的集合级令牌压缩器。NovaCov维护一个容量有界、按新近度加权的历史参考库，并优化一个双分支次模覆盖目标，该目标既保留代表性的当前帧内容，又优先处理历史覆盖不足的信息。这两个分支都是设施选址函数，因此贪心选择保留了经典的(1-1/e)近似保证。在流式和离线基准测试中，NovaCov优于现有的免训练压缩方法，在将LLM预填充延迟降低46%的同时，保留了ReKV 99.6%的准确率。

## Abstract
Streaming VideoLLMs process frames causally while visual tokens grow continuously, making compression essential for controlling prefilling latency and memory. Existing training-free methods independently rank tokens, ignoring marginal-gain interactions among retained tokens. We argue that streaming video token compression should instead be formulated as set selection, where each candidate is valued by what it adds beyond the tokens already retained. Unlike existing set-wise methods designed for offline tasks, streaming makes causal, frame-by-frame pruning decisions, so modeling cross-frame interactions requires an explicit historical reference. This creates a reference-set dilemma: the reference must adequately represent previously conveyed content while remaining bounded for real-time inference. We introduce NovaCov, to our knowledge the first training-free, plug-and-play set-wise token compressor designed for streaming video. NovaCov maintains a capacity-bounded, recency-weighted Historical Reference Bank and optimizes a dual-branch submodular coverage objective that preserves representative current-frame content while prioritizing information insufficiently covered by history. Both branches are facility-location functions, so greedy selection retains the classical (1-1/e) approximation guarantee. Across streaming and offline benchmarks, NovaCov outperforms existing training-free compression methods, retaining 99.6% of ReKV accuracy while reducing LLM prefilling latency by 46%.

### 论文核心问题与整体含义

*   **研究动机与背景**：流式视频大语言模型（VideoLLM）需因果地处理持续到达的视频帧，导致视觉令牌（token）数量不断累积，造成预填充（prefilling）延迟和 KV-cache 内存压力显著增大。因此，在令牌输入 LLM 前进行压缩对实际部署至关重要。
*   **核心问题**：当前的免训练（training-free）压缩方法通常采用“令牌级”（token-wise）策略，为每个令牌独立打分并保留高分者。这种方法忽视了被保留令牌之间的**边际增益（marginal-gain）交互**，可能导致预算浪费在相似或冗余的内容上；而现有的处理此问题的“集合级”（set-wise）方法均为离线设计，无法直接应用于无法获取完整视频流的因果性场景。
*   **整体含义**：本文提出，流式视频令牌压缩的根本问题应是**集合选择**——每个令牌的价值应取决于它在已保留令牌基础之上的**额外贡献**。为了在因果设置下实现这一点，必须引入一个**显式的历史参考**（historical reference），但这面临一个“参考集困境”（reference-set dilemma）：历史参考需要足够全面代表过去信息，其规模又必须**有界**以保持实时效率。

### 论文提出的方法论

*   **核心思想**：NovaCov 将流式令牌压缩建模为一个逐帧的次模覆盖最大化（submodular coverage maximization）问题。方法的关键在于通过一个精心设计的、动态更新的**历史参考库（Historical Reference Bank）** 来代表模型已接收的内容，并以此作为评估新令牌边际价值的参考集。
*   **关键技术细节**：
    1.  **历史参考库（Historical Reference Bank）**：
        *   **结构与容量**：一个容量有界（C）的原型（prototype）集合。解决了历史信息表示必须全面但又必须受大小限制的“参考集困境”。
        *   **更新机制（Match-or-Insert）**：每帧选择后，用选中的令牌更新参考库。若令牌与某一原型相似度超过阈值（θ），则通过指数移动平均（EMA）更新该原型；否则，将其作为新原型插入。
        *   **基于新近度的淘汰机制（Recency-aware Eviction）**：当库满时，淘汰一个实用性得分最低的原型。该得分由新近度（自上次更新以来的帧数）和匹配频次共同决定（公式5：u_j = 2^{-(t-τ_j)/λ} · log(1+n_j)），确保库保留的是当前场景中最可能再现的内容，而非永久存档。
    2.  **双分支次模覆盖目标（Dual-Branch Submodular Coverage Objective）**：
        *   **当前帧分支（Current-Frame Branch）**：确保选中的令牌能很好地代表**当前帧**的空间内容。它通过一个“新异度感知权重（novelty-aware weighting）”进行调制，对历史中未曾出现的内容给予更高的覆盖需求（公式8左半部分：λ_c * Σ ρ_i * c_i(S)）。
        *   **历史新异度分支（Historical-Novelty Branch）**：奖励那些能提供历史参考库**未能覆盖**的新信息的令牌。它定义一个残差覆盖度，只有当当前选择提供的覆盖度超过历史覆盖度时，才计算增益（公式8右半部分：λ_r * Σ max(c_i(S)-h_i, 0)）。
    *   **算法流程**：每一帧到来时，先根据历史参考库计算当前帧每个令牌的“历史覆盖度(h_i)”。然后，以融合双分支后的总目标函数为指导，通过**贪心算法**逐次选择具有最大边际增益的令牌，直至达到预算 K。由于两个分支都是设施选址函数（facility-location functions），其加权组合保持单调次模性，因此贪心选择具有经典的 **(1-1/e) 近似保证**。
