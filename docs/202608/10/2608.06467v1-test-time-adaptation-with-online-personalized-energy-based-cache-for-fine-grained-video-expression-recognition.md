## 摘要
视频中的面部表情识别（FER）具有挑战性，因为模型必须识别随时间演变的微妙情感状态，且这些状态因人而异。尽管视觉-语言模型提供了可迁移的视觉-语义表示，但在主题独立数据上训练的模型在推理时往往因主题特定的分布偏移而性能下降。现有的测试时自适应（TTA）方法通常在推理过程中更新模型参数，增加了计算成本和延迟。基于缓存的方法避免了参数更新，但通常需要足够的目标样本来构建可靠的类别原型，这在自适应早期和罕见类别中难以实现。我们提出能量缓存个性化（EB-CaP），这是一种针对视频FER的基于主体的在线TTA方法，为每个目标视频生成个性化的类别专用原型。EB-CaP使用轻量级能量模型从当前未标注视频中采样原型，并在线填充个性化缓存，无需积累大量目标数据或存储多样的源原型。其能量函数仅依赖预训练的CLIP：目标视频嵌入与类别文本嵌入之间的相似性指导原型采样。同时，正负缓存存储可靠和不确定的目标嵌入。自适应熵门根据不断变化的置信度分布控制缓存更新，而多样性门限制冗余样本。最终预测结合缓存得分与当前CLIP得分。在BioVid、StressID和BAH上的实验表明，EB-CaP在保持低计算和内存开销的同时，优于最先进的TTA方法。代码可在https://github.com/MasoumehSharafi/EB-CaP获取。

## Abstract
Facial expression recognition (FER) in videos is challenging because models must identify subtle, temporally evolving affective states that vary across individuals. Although vision-language models provide transferable visual-semantic representations, models trained on subject-independent data often degrade under subject-specific distribution shifts at inference time. Existing test-time adaptation (TTA) methods commonly update model parameters during inference, increasing computational cost and latency. Cache-based methods avoid parameter updates, but they usually require enough target samples to form reliable class prototypes, which is difficult early in adaptation and for rarely observed classes. We introduce Energy-Based Cache Personalization (EB-CaP), a subject-based online TTA method for video FER that generates class-specific prototypes personalized to each target video. EB-CaP uses a lightweight energy-based model to sample prototypes from the current unlabeled video and populate a personalized cache online, without accumulating large amounts of target data or storing diverse source prototypes. Its energy function relies only on pretrained CLIP: similarities between the target video embedding and class text embeddings guide prototype sampling. In parallel, positive and negative caches store reliable and uncertain target embeddings. An adaptive entropy gate controls cache updates according to the evolving confidence distribution, while a diversity gate limits redundant samples. Final predictions combine cache-derived scores with the current CLIP scores. Experiments on BioVid, StressID, and BAH show that EB-CaP outperforms state-of-the-art TTA methods while maintaining low computational and memory overhead. Code is available at https://github.com/MasoumehSharafi/EB-CaP.

## 方法论

### 核心思想
为每一个传入的目标视频实时构建一个“个性化采样缓存”，利用轻量级能量模型（EBM）从当前视频的表示出发，采样多个类条件嵌入作为缓存原型；同时维护跨视频的正/负目标缓存，通过自适应门控保证可靠性与多样性，最后融合缓存得分与 CLIP 零样本得分。

### 关键技术细节

- **个性化采样缓存（Personalized Sampled Cache）**
  - 能量函数基于冻结的 CLIP 模型：\(E_\theta(z,c) = -z^\top e_c\)，其中 \(e_c\) 为类别文本嵌入，能量越低表示与该类的兼容性越高。
  - 从当前目标视频的归一化表示 \(z_{tgt}\) 初始化，对每个类 \(c\) 运行一条随机梯度朗之万动力学（SGLD）链：
    \[
    \tilde{z}_{k+1} = \tilde{z}_k - \frac{\alpha}{2}\nabla_{\tilde{z}_k}E_\theta(\tilde{z}_k,c) + \sqrt{\alpha}\sigma\epsilon_k,\quad \epsilon_k\sim\mathcal{N}(0,I),
    \]
    每一步后 \(\ell_2\) 归一化。
  - 当采样出的嵌入被预测为类 \(c\)（即 \(\arg\max_{c'}\tilde{z}^\top e_{c'} = c\)）或达到最大步数时停止，每个类采样 \(m_s\) 个嵌入，构成该视频专用的缓存 \(K_s\)。处理完当前视频后清空。

- **目标缓存（Target Caches）**
  - 正缓存 \(K_p\)：存储预测置信度高（低于自适应熵阈值）的目标嵌入及其伪标签。
  - 负缓存 \(K_n\)：存储置信度中等（介于熵阈值之间）且对某个类置信度最低的嵌入，作为负证据。
  - 缓存容量按类限制（\(m_p=5, m_n=4\)），新样本过来时进行替换。缓存跨同一主题的视频维持，更换主题时重置。

- **自适应门控**
  - **熵门**：前5帧使用固定阈值（正缓存 0.5，负缓存 0.8），之后利用当前视频已观测帧的预测熵均值 \(\mu\) 和标准差 \(\sigma\)，动态设定阈值 \(\tau_p=\mu-\sigma\)，\(\tau_n=\mu+\sigma\)。
  - **多样性门**：计算将候选嵌入加入缓存后，该类特征方差的变化 \(\Delta D = D_{after} - D_{before}\)，仅当 \(\Delta D > 0\) 时才保留该候选，避免冗余样本填充缓存。

- **得分融合与预测**
  对当前视频表示 \(z_{tgt}\)，分别计算其与三个缓存中所有嵌入的余弦相似度，按类聚合得到采样缓存得分 \(s_s\)、正缓存得分 \(s_p\)、负缓存得分 \(s_n\)，与 CLIP 零样本得分 \(s_{tgt}\) 线性组合：
  \[
  s_{fuse} = s_{tgt} + s_s + s_p - s_n,
  \]
  最终预测为 \( \hat{y} = \arg\max_c s_{fuse}(c) \)。

整体流程见算法1，所有骨干网络（CLIP 图像/文本编码器、时间编码器）均在测试时保持冻结。

## 主要结论与发现

- EB‑CaP 在三个细粒度视频 FER 数据集上，以显著优于所有对比的零样本、微调和 TTA 方法的 WAR 与 F1 分数，同时保持了**最低的 GPU 显存占用（612 MB）和较低的推理时间（220 ms/批次）**，实现了高效的在线个性化。
- 个性化能量采样缓存能有效解决缓存冷启动问题，生成的类原型即时覆盖所有类别，无需积累目标样本或存储源数据。
- 自适应熵门和多样性门的联合使用，通过仅保留约 5.9% 的高质量候选，大幅提升了缓存的表达质量，避免了噪声和冗余。
- 目标初始化（从当前视频表示开始采样）优于随机噪声初始化，证明了保留目标个体视觉特征的重要性。
- 在多数目标对象上 EB‑CaP 均取得最佳，仅在个别困难对象上被某些方法超越，说明方法具有较强的普适性但仍有提升空间。

## 优点

- **无需参数更新**：完全冻结模型，避免梯度计算和模型漂移，适合资源受限的实时应用。
- **快速冷启动**：采样缓存随视频即时生成所有类的原型，不依赖历史样本积累。
- **个性化强**：SGLD 从当前视频表示初始化，保留目标个体的视觉细节，且无需存储任何源数据。
- **高效**：内存和计算开销极低，显著优于多数优化型 TTA 方法。
- **双重门控设计**：熵门保证可靠性，多样性门防止冗余，提高了缓存质量。
- **实验扎实**：多数据集、多基线、逐主题分析、大量消融实验，结论可信度高。

## 不足与局限

- **数据集局限性**：仅在疼痛、压力和犹豫/矛盾三类特定情感数据集上验证，未在更通用的表情数据集（如 Aff-Wild2、AFEW）上测试，泛化性有待进一步验证。
- **SGLD 采样开销**：虽然轻量，但每条链仍需最多20步迭代，对于非常长的视频序列，累积开销可能不可忽略，且实时性在更苛刻的嵌入式场景下未验证。
- **门控依赖前几帧**：前5个时间窗口使用固定熵阈值，若视频开头就出现高噪声或困难帧，可能引入错误样本。
- **缓存重置**：缓存随主题重置，未考虑相同主题可能多次出现的情况，无法跨会话积累长期知识。
- **依赖 CLIP 模型**：能量函数和文本提示均依赖 CLIP，若替换为其他 VL 模型，能量采样和文本指导性能未知。
- **隐私和安全性**：文中未讨论缓存中存储目标面部嵌入可能涉及的隐私风险。
- **性能增益在 BAH 上较小**：在 BAH 数据集上的提升有限，表明对某些极细粒度或高度模糊的表达，单纯依靠缓存改进可能已接近瓶颈。
